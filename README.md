# navigation_module

Переиспользуемые вспомогательные средства для **плоской (2D) навигации по точкам** для роботов, где объединяют **позицию GPS** и **курс IMU** (yaw или кватернион). Библиотека **не привязана к железу**: интеграция с реальной платформой через реализацию `RobotController`.

## Возможности

- Перевод координат GNSS в **локальную плоскость восток–север** с произвольным началом (обычно первый фикс).
- **Расстояние**, **пеленг на цель**, **нормализованная ошибка курса** и проверка **достижения цели** с допуском по радиусу.
- Простой **фильтр нижних частот** для шумных координат GPS.
- Управление по «позе»: \(F = k_1 \, d \cos(\theta_e)\), \(T = k_2 \, \theta_e\) и разнесение на **левый/правый дифференциальный канал**.
- **Дискретные команды**: `turn`, `move`, `stop` через `generate_command`.
- **MockController** и мост `execute_command` для тестов и симуляции.
- **Вывод**: словарь Python, строка JSON или файл JSON; **шаблоны строк** с безопасной подстановкой при отсутствующих ключах.
- Папка **`portable_gps_nav/`**: только расстояние между точками и угол поворота к цели — можно скопировать отдельно, без установки всего проекта (см. `portable_gps_nav/README.md`).

## Структура проекта

```text
navigation_module/
  __init__.py
  core/           # геометрия, GPS, ориентация, навигация, фильтры
  control/        # RobotController, MockController, исполнитель команд
  io/             # режимы вывода, шаблоны
  config/         # NavigationSettings
portable_gps_nav/ # автономный минимум: расстояние и угол к цели (дубликат формул)
tests/
examples/
```

## Математика (кратко)

- **Расстояние по дуге большого круга** (гаверсинус) между точками в широте/долготе WGS84.
- **Локальные XY**: касательная плоскость к Земле в выбранном начале; \(x\) — восток, \(y\) — север (подходит для типичных масштабов полевого робота).
- **Пеленг** от текущей точки к цели приводится к той же конвенции, что и `atan2(dy, dx)` в этой плоскости.
- **Ошибка курса** \(\theta_e = \mathrm{wrap}(\theta_{\mathrm{bearing}} - \psi)\) через \(\mathrm{atan2}(\sin\theta_e,\cos\theta_e)\), чтобы угол оставался в \((-\pi,\pi]\).
- **Закон подхода**: \(F\) уменьшается при рассогласовании по курсу (\(\cos\theta_e\)), \(T\) тянет \(\theta_e\) к нулю; колёса/тяга — через \(F \pm T\).

## Система команд

`generate_command(distance_m, angle_error_rad, angle_turn_threshold_rad, distance_move_threshold_m)` возвращает:

| Приоритет | Условие | Полезная нагрузка |
|-----------|---------|-------------------|
| `turn`    | модуль угловой ошибки курса больше порога (`angle_turn_threshold_rad`) | `{ "type": "turn", "angle_deg": <float> }` |
| `move`    | расстояние больше порога | `{ "type": "move", "distance_m": <float> }` |
| `stop`    | иначе | `{ "type": "stop" }` |

`execute_command(controller, cmd)` вызывает соответствующие методы `RobotController.turn` / `move` / `stop`.

## Подключение железа

Наследуйте `navigation_module.control.interface.RobotController` и свяжите `turn`, `move` и `stop` с вашими приводами или интерфейсами ROS 2 / Gazebo. Слой навигации не импортирует проприетарные SDK.

## Установка

```bash
cd navigation_module   # корень репозитория с pyproject.toml
python -m pip install -e ".[dev]"
```

## Тесты

```bash
pytest
```

## Демо

Симулируются шумный GPS, сглаженные фиксы, последовательность точек, вывод mock-привода и **траектория с курсами** в matplotlib:

```bash
python examples/demo_navigation.py
```

Рядом со скриптом сохраняется `examples/demo_navigation.png`; окно графика откроется, если среда поддерживает GUI.

## Зависимости

- Python ≥ 3.10  
- `matplotlib` (демо / визуализация)  
- `pytest` (опционально, extra `dev`)
